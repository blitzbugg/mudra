How to contribute

  1. Fork the Mudra repository
  2. Create your SVG (24×24 viewBox, clean paths, no scripts)
  3. Use the Metadata Editor to generate valid metadata.json
  4. Place files in assets/india/kerala/<category>/<asset-name>/
  5. Run npm run validate to check your contribution
  6. Open a Pull Request — automated checks will verify everything
